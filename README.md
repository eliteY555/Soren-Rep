# Soren-Rep

个人项目仓库。

## 项目分支

- [SDX](https://github.com/eliteY555/Soren-Rep/tree/SDX) — 代驾服务平台，基于 Spring Boot 的代驾调度与管理系统。
- [Sky](https://github.com/eliteY555/Soren-Rep/tree/Sky) — 校园外卖平台，支持微信支付、订单管理、购物车等功能的餐饮外卖系统。
- [TaiLai](https://github.com/eliteY555/Soren-Rep/tree/TaiLai) — 合同管理系统，支持合同发布、签署审批、模板管理等全生命周期管理。
- [Voice-Assistant](https://github.com/eliteY555/Soren-Rep/tree/Voice-Assistant) — 语音助手，基于 AudioContext 实现语音识别与合成的智能助手应用。
- [YZT-medicine](https://github.com/eliteY555/Soren-Rep/tree/YZT-medicine) — 智慧医疗平台，集成 LangChain4j AI Agent，涵盖医生管理、诊疗记录、智能问诊等功能。
